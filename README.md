A programming language project inspired by Python, with a custom virtual machine based on Von Neumann architecture. The project explores language implementation, CPU/RAM components, and instruction execution.

**Tech:** Python · Compilers · Computer Architecture

### 🃏 Bololó — Distributed Card Game
A web-based card game project with distributed components. I worked on game logic in Go and component integration through an API Gateway implemented with Traefik.

**Tech:** Go · Traefik · API Gateway · Software Architecture
